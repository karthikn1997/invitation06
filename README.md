# invitation06

Royal South Indian Wedding E-Invitation Web Application.

## ✨ Features
- **Hero Cover Animation**: Traditional South Indian couple walking feet, hanging marigold malas, line-by-line animated names & luxury date badge.
- **Our Moments Deck**: Interactive Polaroid cards with authentic South Indian bridal & groom photography.
- **Subha Muhurtham Details**: Mandapam teak pillar, glowing brass Kuthuvilakku lamp, and Muhurtham timings.
- **Wedding Schedule**: Minimalist royal sandalwood stationery layout with 4 auspicious ceremonies.
- **Sacred Saptapadi Countdown**: Real DSLR wedding photography of little-finger holding hands with tied Brahma Mudi knot and live ticking countdown timer.
- **Mandapam Venue & Location**: Temple town landscape with one-tap Google Maps directions, Add to Calendar, and Call Hall.
- **Direct WhatsApp RSVP**: Interactive attendance confirmation connecting directly to WhatsApp.
- **Background Wedding Music**: Auspicious wedding BGM with floating golden vinyl disc controls and auto-play on touch.

## 🚀 Setup & Run
```bash
npm install
npm run dev
```

## 📦 Build for Production
```bash
npm run build
```
